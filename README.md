# ミールログ

食事のカロリー・栄養素と体重を記録して、その日の食生活を採点するWebアプリ（PWA）。
スマートフォンのブラウザで開き、ホーム画面に追加してアプリのように使えます。

## 特徴

- **食事記録** — 食品成分表2,538品目から検索、よく使う食品はワンタップ、履歴からの再入力
- **バーコード** — カメラで読み取り。一度登録すれば次回から自動で呼び出し
- **カラダ記録** — 体重・体脂肪率・歩数のほか、任意項目（筋トレの回数など）、お通じ、トイレ回数をワンタップで記録
- **栄養採点** — 14項目の過不足を100点満点で採点し、不足している栄養素を多く含む食品を提案
- **グラフ** — 体重・体脂肪率の推移と、摂取カロリーの日別推移
- **完全ローカル保存** — 記録は端末のブラウザ内にのみ保存され、サーバーには一切送信されません

## データの出典

- 栄養成分値: [日本食品標準成分表（八訂）増補2023年](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html) / 文部科学省
- 目標量の基準: 日本人の食事摂取基準（2025年版） 18〜64歳の推奨量・目安量・目標量
- 商品情報の検索: [Open Food Facts](https://world.openfoodfacts.org/)（利用者投稿型データベース）

## 注意

健康管理の補助を目的としたもので、医療上の助言ではありません。
治療中の方や妊娠・授乳中の方は、医師・管理栄養士の指示を優先してください。
